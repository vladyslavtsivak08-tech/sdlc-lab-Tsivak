## 1. Планування

> “Користувач повинен мати можливість миттєво згенерувати надійний пароль заданої довжини із використанням різних типів символів (літери, цифри, спецсимволи) та скопіювати його в один клік.”

## 2. Аналіз вимог (User Stories)
1. Як користувач, я хочу вибирати довжину пароля (від 8 до 30 символів), щоб відповідати технічним вимогам безпеки різних сайтів. ✅ **(Must have)**
2. Як користувач, я хочу керувати набором символів (включати/виключати цифри, великі літери, спецсимволи), щоб створювати паролі під конкретні правила авторизації. ✅ **(Must have)**
3. Як користувач, я хочу бачити індикатор складності згенерованого пароля (слабкий, середній, надійний), щоб оцінювати його безпеку.
4. Як користувач, я хочу скопіювати згенерований пароль у буфер обміну в один клік, щоб швидко вставити його у потрібне поле.
5. Як користувач, я хочу мати кнопку «Згенерувати знову», щоб швидко оновити пароль, якщо поточний мені не подобається.

## 4. Реалізація (Псевдокод алгоритму)
Алгоритм ключової функції генерації пароля на основі вибраних користувачем параметрів:

```pseudo
function generatePassword(length, useUppercase, useNumbers, useSpecial):
    if length < 8:
        return "Помилка: Занадто коротка довжина"
        
    lowercaseChars = "abcdefghijklmnopqrstuvwxyz"
    uppercaseChars = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    numberChars = "0123456789"
    specialChars = "!@#$%^&*()_+-=[]{}|;:,.<>?"
    
    // Базовий набір символів завжди включає малі літери
    allowedChars = lowercaseChars 
    
    if useUppercase == true:
        allowedChars = allowedChars + uppercaseChars
    if useNumbers == true:
        allowedChars = allowedChars + numberChars
    if useSpecial == true:
        allowedChars = allowedChars + specialChars
        
    password = ""
    for i from 1 to length:
        randomIndex = getRandomIndex(allowedChars)
        password = password + allowedChars[randomIndex]
        
    return password
```

## 5. Тестування
Для перевірки коректності роботи ключової функції генерації пароля розроблено 3 тест-кейси:

1. **Тест на довжину:**
   * *Дія:* Передати в функцію `length = 12`.
   * *Очікуваний результат:* Довжина згенерованого рядка дорівнює рівно 12 символам.
2. **Тест на виключення символів:**
   * *Дія:* Виставити `useNumbers = false`, `useSpecial = false`, `useUppercase = false`.
   * *Очікуваний результат:* Згенерований пароль складається виключно з малих літер латинського алфавіту (наприклад, `xkvwerty`).
3. **Тест на граничні значення (валідація):**
   * *Дія:* Передати в функцію `length = 5`.
   * *Очікуваний результат:* Система не генерує пароль, а повертає повідомлення про помилку валідації.

## 6. Висновки
Для розробки генератора паролів найкраще застосувати **Agile-модель (а саме фреймворк Scrum чи Kanban)**. 

* **Чому:** Проєкт невеликий, його базовий функціонал (генерація простого рядка) можна реалізувати за одну коротку ітерацію (спринт) тривалістю в кілька днів. 
* Наступні ітерації дозволять гнучко нарощувати можливості застосунку на основі відгуків: додавати індикатор складності, історію генерацій або мобільну версію. 
* Використання *Waterfall* тут недоцільне через надлишкову бюрократію для міні-проєкту, а *Spiral* модель занадто фокусується на аналізі великих фінансових ризиків, яких тут немає.
